# 在钢琴旁用屏幕录音，无需电脑

这不是“标定钢琴与人声”，而是保存麦克风原始音频，用于听检、检查采样质量及后续评估识别效果。`Saved` 只表示 WAV 已保存并通过读回校验，**不表示识别模型已训练，也不表示这段声音被识别为钢琴**。

## 先在电脑旁更新固件

1. Arduino 项目文件夹设为 `/Users/leon/iot-pianoTimer`。
2. 打开 `PianoTimer/PianoTimer.ino`。
3. 开发板 ESP32S3 Dev Module；Flash 16MB；PSRAM OPI；分区必须选择 **16M Flash (3MB APP/9.9MB FATFS)**。
4. 保持 `Erase All Flash Before Sketch Upload` 为 Disabled。
5. 使用现有 USB 设置编译上传。无需增加 SD 卡。

这里默认使用你已经观察到有响应的 **I2S 左声道**。如果设备之前保存过其他麦克风配置，则仍使用保存的配置。没有保存配置时，录音按钮也能工作，但练琴计时先保持关闭，等听检确认。

## 到钢琴旁操作

1. 给设备供电，放在平时使用的位置。
2. 点击屏幕底部 **Record**。
3. 如果出现 `Storage setup`，说明内置数据存储无法挂载。**只有确认可以清除该数据区原有文件时，才点击 `Erase & init`。** 不确定则点 Cancel；不会自动格式化。
4. 屏幕倒数 `Get ready: 3…2…1`。
5. 显示 `Recording: 5 s` 后开始弹琴或说话，连续录制约 5 秒。
6. 等待 `Saving and checking...`。
7. 成功显示 `Saved` 和文件名，例如 `piano-0001.wav`，约 4 秒后回到正常界面。

可重复按 Record，下一次保存为 `piano-0002.wav`，依次编号，不覆盖已有录音。可以分别录讲话、钢琴、环境安静、钢琴加讲话；请记下每个编号对应什么声音，设备不会自动标注类别。

录音和保存期间练琴时间暂停，Reset/Record 暂时禁用，双核 CPU 显示仍可更新。结束后如原先正在正常监听，则恢复监听，并断开此前待补计的间隔；测试过程不计入练习。

每段 WAV 为 16kHz、16位、单声道、5秒，160044 字节。文件保存到内置 Flash，正常断电后仍保留。看到 Saved 之前不要断电。录音失败、存储已满、PSRAM 不可用或保存校验失败时只显示错误，不显示 Saved。

初始化只针对所选分区方案的 `ffat` 数据区，不是清空整块芯片；它仍会清除该数据区内所有原有文件。程序拒绝在其他分区布局下初始化，请先核对分区菜单。

## 回到电脑旁导出以前录好的文件

不需要在钢琴旁运行任何命令。回到电脑旁：

1. USB 连接设备，保持运行 **PianoTimer** 固件，不要换回 MicTest。
2. 完全关闭 Arduino 串口监视器；若端口仍被占用，按 ⌘Q 退出 Arduino IDE。
3. 在终端运行（端口以当前实际端口为准）：

```sh
cd /Users/leon/iot-pianoTimer
python3 tools/export_recording.py --port /dev/cu.usbmodem13301 --number 1 --output /private/tmp/piano-0001.wav
```

`--number 1` 对应 `piano-0001.wav`。导出第二段改成 `--number 2`，并使用另一个输出文件名。

工具使用 115200 波特率，先取出完整文件、校验 CRC 和 WAV 格式，再保存到电脑。输出路径已存在时拒绝覆盖。导出不会启动新录音，也不会删除设备上的原文件。

如忘记编号，可用 Arduino 串口监视器（115200）发送 `list`，查看 `RECORD piano-xxxx.wav ...` 列表；查完关闭监视器再导出。

## 听检后启用计时

1. 打开导出的 WAV，确认声音清楚、音调与速度正常，无持续数字噪声。
2. 若此前尚未保存麦克风设置，打开 **PianoTimer 固件**的串口监视器，波特率 115200，发送完整单词 `verify` 并回车。
3. 看到 `MIC_CONFIG_SAVED` 后，重启设备，并保持环境安静约 4 秒进行背景噪声校准。
4. 然后开始计时识别测试。已经保存过正确配置的设备不必重复 verify。

`verify` 是你听检后的人工确认，不是自动训练。原有上电约 4 秒的步骤只是估计背景噪声门限，也不是钢琴/人声分类标定。

## 已验证与待验证

已验证：WAV 头格式、导出协议成功路径、传输截断、文件缺失、尺寸异常、CRC 损坏拒绝；固件编译。

待实机验证：触摸按钮位置、内置存储初始化、录音连贯性、Saved 后断电重启再导出，以及 WAV 实际声音。尚不能保证可靠排除人声。
